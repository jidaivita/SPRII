**Source:** the V1.0 tactile dataset associated with *Embedded real-time objects

## Burgers

The Burgers preview redraws a released trajectory from **Neural Operator Discovery Burgers Dataset**, by **Zituo Chen**, [Zenodo record 20372988 / DOI 10.5281/zenodo.20372988](https://zenodo.org/records/20372988), released under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The spatial curve and space–time field use the `RdBu_r` display colormap and fixed signed color limits. All 101 stored states retain their order and numerical values; simulation time 0–5 seconds is displayed at 10 frames/s. The poster selects frame 50; the gallery copies the full project-page poster with its curve, field and colorbar. The included poster and its SVG wrapper are shared under CC BY 4.0 with this attribution and change notice. These are numerical-data views, not native camera frames or learned predictions.

## FitzHugh–Nagumo

The FHN model and display palette follow the DR2D generator in **Neural Operator Discovery Code**, by **Zituo Chen**, [Zenodo record 20406332 / DOI 10.5281/zenodo.20406332](https://zenodo.org/records/20406332). This separate **software** record is released under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The displayed trajectory was newly generated by a Python reimplementation of the released equations, periodic stencil and RK4 integration (seed 42, k = 0.03, beta = 0.20). It is a visualization-only trajectory, not an official released FHN trajectory or a sample from the Burgers data record. Both fields use the upstream generator's `summer` colormap, fixed shared signed color limits and 101 stored states over simulation time 0–10 seconds, displayed at 10 frames/s. The gallery copies the project-page poster of both fields at the final state. The code-record license is cited for the generator source; the Burgers data license is not used as the licensing basis for the generated trajectory.

## Overcooked

Rendering adapts work by the **JaxMARL contributors** (Alexander Rutherford et
al.): the [Overcooked V2 visualizer](https://github.com/FLAIROx/JaxMARL/blob/main/jaxmarl/viz/overcooked_v2_visualizer.py)
and [grid-rendering routines](https://github.com/FLAIROx/JaxMARL/blob/main/jaxmarl/viz/grid_rendering_v2.py).
The repository distributes the software under
[Apache License 2.0](https://github.com/FLAIROx/JaxMARL/blob/main/LICENSE).

The archived 120-action UtilityGreedy sequence is replayed with the original
environment and seed. Recorded positions, inventories, recipes and rewards
match; four original-renderer frames also match the archived images pixel for
pixel. Only the presentation colors change: a warm-white floor, pale counters,
purple/gold partners and gray pots. All 121 frames retain their order and 120 ms
display duration. The paper thumbnail shows the same rendered board; the
GitHub preview is an exact copy of the project-page poster. This is a scripted
controller demonstration, not a trained-policy result. The renderer's software
license is not asserted as a universal license for generated footage.

## Pendulum

The dynamics use the released **CaDM** environment by **Kimin Lee, Younggyo Seo, Seunghyun Lee, Honglak Lee and Jinwoo Shin**, *Context-aware Dynamics Model for Generalization in Model-Based Reinforcement Learning* (ICML 2020), from the [official repository](https://github.com/younggyoseo/CaDM). The display reproduces the geometry of [OpenAI Gym 0.16 Pendulum](https://github.com/openai/gym/blob/0.16.0/gym/envs/classic_control/pendulum.py); Gym is copyright 2016 OpenAI and distributed under the [MIT License](https://github.com/openai/gym/blob/0.16.0/LICENSE.md). This is a new fixed-input torque demonstration using unchanged CaDM reset/step and normalization methods. The geometry and colors were redrawn with Pillow, with torque and response overlays, rather than captured as native Gym pixels. The 161 frames are displayed at 20 frames/s, with a selected project-page poster copied byte for byte into this gallery. Gym's license is not extended to CaDM; the linked CaDM repository provides no top-level license, and no separate CaDM licensing grant is claimed here.

## PokeWorld

The preview and video render the same recorded method-figure histories with the
paper's gray pusher, orange object and light floor. All 24 stored states and
recorded actions retain their values and order; there is no interpolation or
new physical simulation. The camera is wider for the two-history video and
closer for the paper/project-page summary image used here. Normalized-action
arrows are display overlays, not calibrated force measurements.

This is a human-facing MuJoCo rendering. The model still receives its unchanged
64 × 64 grayscale DiskRenderer observations; neither the model renderer nor
training inputs are modified. The gallery copies the project-page close-up
preview, while the manifest separately records the wide video-poster hash.

## SpringWorld, Swimmer and D-Clean

SpringWorld retains its force-and-release physics demonstration. Object 1 is
deep teal and object 2 is copper/orange, following the paper renderer's object
identities. Only those two display materials change: the 201 archived states,
actions, geometry, camera, arrows and 20 frames/s playback remain unchanged.
This is the existing demonstration trajectory, not the paper-atlas trajectory
or a learned prediction. Swimmer
re-renders the existing recorded three-link demonstration on a light floor
with a deep-teal body and gray trail, matching the paper's display. Geometry,
state/action samples, and drive/reversal/off intervals remain unchanged; every
fourth stored state appears at 25 frames/s without interpolation. No new physics
steps or evaluation results are produced by this presentation update.
SpringWorld, Swimmer and the PokeWorld display use **MuJoCo**, whose software is
distributed under [Apache License 2.0](https://github.com/google-deepmind/mujoco/blob/3.3.5/LICENSE).
This acknowledges the software without assigning that license to every
generated image.

D-Clean redraws stored numerical states and actual forces at half physical
speed, with force/drag overlays. Its full poster shows the trajectory, velocity
and applied-force panels. These original project visualizations add no
learned-model predictions.

The package includes ten PNG previews and three original SVG schematics with
their SVG frames. Video files remain on the project page. The images use the
same sources as that page; changes to visual presentation do not alter model
observations, training code or experimental results. Per-file source and card
hashes are in [the gallery manifest](../assets/environments/gallery.json).
Benchmark implementation licenses remain recorded in
[third-party notices](../THIRD_PARTY_NOTICES.md).
