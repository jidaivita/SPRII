# Contributing

This is the public research implementation of SPRII. Keep changes focused and include a
small check that demonstrates the changed behavior. Preserve the documented
data splits, checkpoint-selection rules, relation controls and evaluation
budgets when comparing results.

Use relative resource paths or explicit command-line configuration. Do not
commit credentials, machine-specific paths, generated datasets, checkpoints
or run logs. Preserve third-party notices when modifying derived code.
