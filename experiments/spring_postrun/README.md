# SpringWorld sensitivity and frozen-reader evaluation

The sensitivity wrappers retain the final source recipe and insert gradient diagnostics into the existing forward graph. They do not add another forward pass or optimizer update. The callback verifies unchanged random-number state and pre-existing parameter gradients. The source recipe is 10,000 steps, 48 pairs per batch and 96 history frames. The sensitivity grid is `(lambda_p, lambda_x) = (1,.1), (.25,.1), (4,.1), (1,.025), (1,.4)` with source seeds 0, 1 and 2.

`spring_sensitivity_resume_v3.py` exposes `smoke`, `train` and `audit`. It requires an explicit checkpoint commit and SHA-256 for the intended continuation. `spring_fast_batch.py` supplies the checked batching implementation. These wrappers do not imply that every ongoing source run has finished.

`spring_postrun_v1.py` exposes `export`, `fit`, `evaluate` and `probe`. Source weights remain frozen during all reader and physical-probe phases. The common decoder/probe is fitted using training examples only. The full configuration is present in `reader/sprii_next/protocol.py`: reader seeds 0, 1, 2; 10,000 steps; batch size 256; learning rate `3e-4`; weight decay `.05`; warmup 500; gradient clip one. The physical ridge uses alpha one and training-standardized log mass, drag and stiffness. Bootstrap draws are 10,000 with physical system as the sampling unit.

The required native snapshot is `benchmarks/springworld/native`, and the immutable research bank belongs under `data/springworld/research_bank`. Bank manifests, source checkpoint completion records and the original training policy are runtime input contracts. They are checked, not generated by pretending an unrelated checkpoint or dataset matches. `SPRII_ROOT` selects the checkout/data root.

The `reader/` directory is the reader code snapshot bundled with this postrun implementation; it is isolated from the core package so that a later version cannot silently change the fitted-readout protocol. These experiments use training/validation development data (`test_read=false`); they are not sealed-test evidence.
